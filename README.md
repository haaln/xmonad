# XMonad

XMonad window manager with xmobar status bar

## Requirements ## 

- [ghc](https://www.haskell.org/ghcup/)
- [xmonad](https://xmonad.org/download.html)
- xmobar
- alacritty
- [VictorMono NF](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/VictorMono.zip)
- [JetBrainsMono NF](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/JetBrainsMono.zip)
